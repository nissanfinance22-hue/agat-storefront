# AGAT Storefront

Crie um site/app profissional e responsivo para a loja AGAT.

Visual: vermelho + preto + branco, moderno e elegante. Use as imagens da AGAT que vou enviar.

TELEFONES:

9628-1419

3623-1419

8893-1419

Não invente outros dados. Deixe WhatsApp, endereço, Instagram e horários configuráveis.

CATÁLOGO:

Roupas, acessórios, buquês, cestas, café da manhã, presentes, Xerox/impressões e outros.

Cada produto deve ter:

imagem, nome, categoria, descrição, favoritos, detalhes e adicionar ao carrinho.

NÃO MOSTRAR PREÇOS.

FUNCIONALIDADES:

- Busca e filtro por categoria

- Favoritos com localStorage

- Carrinho com quantidade, remover e limpar

- Botão "ENVIAR PEDIDO PELO WHATSAPP"

- Gerar automaticamente mensagem com produtos e quantidades, sem preços

- Botão para falar com a AGAT pelo WhatsApp

HOME:

Header + logo + carrossel de imagens + categorias + produtos + contato + rodapé.

IMAGENS:

O projeto será publicado no Cloudflare Pages. As imagens precisam funcionar após o deploy.

Salvar dentro de:

public/assets/agat/

Usar caminhos como:

 /assets/agat/produtos/produto-01.jpg

NUNCA usar C:\, /mnt/data/, blob:, file:// ou URLs temporárias.

Prioridade: FUNCIONAMENTO > CARRINHO > FAVORITOS > WHATSAPP > IMAGENS > VISUAL.

Mobile-first e compatível com computador.

Não criar pagamento, checkout ou funcionalidades extras desnecessárias.

Antes de finalizar, verifique o build e se todas as imagens funcionam em produção.
